02 Disciplines Six disciplines behind everything we ship.

The work spans the full system.

Our work draws on six core technical disciplines. These are areas we build in, not a catalogue of client services. Examples below describe our own systems and their intended uses, not client work.

  1. System software

    The code that does the work: event handling, storage, and the rules that keep a system correct. Example: the event logging core of Enoch, which records customer events in a private instance.

  2. User applications

    The interfaces people use: what a user sees, enters, and gets back from a system. Example: the Find Your Grants, Canada interface, which presents grant matches to a business owner.

  3. Middleware and APIs

    The connections between parts: how one piece of software talks to another, reliably. Example: the bridge that carries a record hash from a private instance to the public Hedera network.

  4. Data and analytics

    The data a system holds, and the analysis that turns it into answers. Example: the grant catalogue data behind Find Your Grants, Canada, used to match a business with grants.

  5. Infrastructure and deployment

    Where a system runs, and how it gets there: hosting, delivery, and operation. Example: the hosting that serves goodcode.ca and enoch.goodcode.ca.

  6. Web 4.0 contrivance engineering

    A method we named, replacing an entire category of software with a smaller, cleverer mechanism that does the same job with less overhead. Example: serving a static site directly from version control, instead of running a content management system.

04 Current project Private data, public proof.

We're currently working on Enoch.

Enoch is a tamper-evident event logging and documentation archiving system. Customer events and documents stay private in customer-controlled systems, while cryptographic hashes and trusted timestamps are anchored to the Hedera public network. The result is private data with public proof: records whose integrity anyone can verify without ever seeing their contents.

Enoch is being built for regulated professional firms that depend on the integrity of their records, including law firms, medical practices, and accountants. It is built for organizations that must prove what happened and when, to auditors, regulators, and courts.

Pilot status. Pilot discussions are underway with our own projects, including Find Your Grants, Canada as the first pilot client once it is launched and has transactions. No live pilot deployment is running yet.

Limits. Enoch has no certifications, no security audit, no privacy impact assessment, no court acceptance, and no regulator endorsement. See the Enoch page for the full status.

What is Web 4.0 Contrivance Engineering?

Web 4.0 is the name for the intelligent web. AI agents form the interface layer, and memory is shared across version control, databases, and decentralized ledgers. Functionality is managed through modularity and microservices, so each capability can be built, changed, or replaced independently, where traditional monolithic systems tie every change to the risk of breaking the whole. Contrivance engineering is the method behind it, replacing an entire category of software with a smaller, cleverer mechanism that does the same job with less overhead. The content management system is the first casualty. We are a systems company, not a website development company: this is how we engineer systems, not a service we sell.
