Product Enoch

Enoch

Tamper-evident event logging and documentation archiving for regulated professional firms.

Enoch is a tamper-evident event logging and documentation archiving system. Customer events and documents stay private in customer-controlled systems, while cryptographic hashes and trusted timestamps are anchored to the Hedera public network. The result is private data with public proof: records whose integrity anyone can verify without ever seeing their contents.

Status

In development, pre-launch. Pilot discussions are underway with our own projects, including Find Your Grants as the first pilot client once it is launched and has transactions. No live pilot deployment is running yet.

Limits

Enoch has no certifications, no security audit, no privacy impact assessment, no court acceptance, and no regulator endorsement. Enoch does not prove that a record is true. It proves, if a record was anchored, whether that record has changed since anchoring. It does not prove completeness, and it does not replace the systems of record you already use.

Proof, one example

Record EN-2026-0001, file engagement-letter.pdf, captured 2026-10-15T21:42:18Z, has SHA-256 digest 01ae732d5bf4476f8159d2a02e23c58a6f33044d0dae2d0bd8a605c057187284. That digest was recomputed from the record and matches exactly. Live anchor: the record is anchored on Hedera mainnet, topic 0.0.10969062, message sequence 1. See the anchored record on HashScan.
