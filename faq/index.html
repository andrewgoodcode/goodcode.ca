What is Web 4.0 Contrivance Engineering?

Web 4.0 is the name for the intelligent web. AI agents form the interface layer, and memory is shared across version control, databases, and decentralized ledgers. Functionality is managed through modularity and microservices, so each capability can be built, changed, or replaced independently, where traditional monolithic systems tie every change to the risk of breaking the whole. Contrivance engineering is the method behind it, replacing an entire category of software with a smaller, cleverer mechanism that does the same job with less overhead. The content management system is the first casualty. We are a systems company, not a website development company: this is how we engineer systems, not a service we sell.

What is Enoch?

Enoch is a tamper-evident event logging and documentation archiving system. It is in development and pre-launch. Customer events and documents stay private in customer-controlled systems, while cryptographic hashes and trusted timestamps are anchored to the Hedera public network. Pilot discussions are underway with our own projects, including Find Your Grants as the first pilot client once it is launched and has transactions. No live pilot deployment is running yet. See the Enoch page for the full status and limits.

What is Find Your Grants?

Find Your Grants matches Canadian businesses with grants. It is a second system of the company, in development and pre-launch. It is also the first pilot client for Enoch, once it is launched and has transactions.

How do I verify a record?

Open the receipt for the record and follow its HashScan link, or go to HashScan and open Hedera mainnet topic 0.0.10969062. The message holds the record digest and the envelope it was computed from. Recompute the digest from the envelope using the canonicalization spec and compare the two.

What does the anchor prove, and what does it not prove?

The anchor proves that the envelope for a record existed at the consensus timestamp and has not changed since. It does not prove the contents of the file itself, only the envelope. The envelope names the file; the file contents are not on the ledger.
