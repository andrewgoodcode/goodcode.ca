Accessibility Statement

Last updated: November 26, 2026.

Our target

We aim for this site to meet WCAG 2.2 level AA. The site has not had a formal accessibility audit, so this statement describes the features in place and the limitations we know about, not a certified result.

Features in place

  • A skip link, "Skip to main content", as the first link on every page, which moves focus to the main content.
  • Headings in a logical order, with one main heading per page.
  • Text that wraps with balance on headings and pretty on paragraphs, so lines do not break awkwardly.
  • Interactive targets of at least 44 pixels: navigation links, buttons, the hamburger menu, and form fields.
  • Visible focus outlines on links, buttons, and form fields.
  • Support for reduced motion: animations stop when your system asks for reduced motion.
  • Support for light and dark colour schemes, following your system setting.
  • The operating model diagram has a text description (aria-label) that states what it shows.

Known limitations

  • The operating model diagram is an image with a text description, not a table. A text version of the eight stages (Research, Analyze, Plan, Design, Build, Test, Deploy, Operate) is in the diagram description, but the full diagram is not available as text.
  • Some labels use small mono type (11 to 12 pixels). They are in the site design, and we are reviewing their size and contrast.
  • The cookie banner and the contact form have not been tested with a screen reader.

Feedback

If you have trouble using this site, email hello@goodcode.ca with the subject "Accessibility". Tell us the page, the problem, and the browser or assistive technology you use, and we will reply within 30 days, and sooner if we can.
